## Описание
Выполнение лабораторной работы № 2 «Структурное программирование на Python».

Цель работы — научиться использовать переменные, условия, циклы и функции в Python.

Все задания находятся в файле `lab2_variant1.py`. Каждое задание оформлено отдельной функцией.

## Задания средней сложности

### Задание 1: Таблица умножения
Функция multiplication_table() выводит таблицу умножения от 1 до 10. Два вложенных цикла for перебирают множители i и j. Их произведения выводятся через пробел, а после каждой строки выполняется переход на новую строку.

### Задание 3: Факториал числа
Функция calculate_factorial(n) вычисляет факториал числа с помощью math.factorial(n) из библиотеки math. Результат сохраняется в переменную result_factorial, выводится на экран и возвращается из функции. В программе функция вызывается для числа 5, поэтому результат равен 120.

### Задание 5: Список простых чисел до 100
Функция prime_numbers() перебирает числа от 2 до 100. Для каждого числа цикл проверяет все возможные делители от 1 до самого числа. Если остаток от деления равен нулю, счётчик count увеличивается на 1. Числа с двумя делителями добавляются в список table_prime. Готовый список простых чисел выводится на экран.

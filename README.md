## Задания средней сложности

### Задание 1: Таблица умножения
Функция `multiplication_table()` выводит таблицу умножения от 1 до 10. Два вложенных цикла `for` перебирают множители `i` и `j`. Произведения выводятся через пробел, а после каждой строки выполняется переход на новую строку. Функция ничего не возвращает, только печатает результат.

### Задание 3: Факториал числа
Функция `calculate_factorial(n)` вычисляет факториал числа с помощью `math.factorial(n)` из библиотеки `math`. Результат сохраняется в переменную `result_factorial`, выводится на экран и возвращается из функции. В программе функция вызывается для числа 5, поэтому результат равен 120.

### Задание 5: Список простых чисел до 100
Функция `prime_numbers()` перебирает числа от 2 до 100. Для каждого числа проверяются делители в диапазоне от 2 до `√n`. Если найден хотя бы один делитель, число не является простым. Простые числа добавляются в список `table_prime`, который выводится на экран и возвращается из функции.

## Задания повышенной сложности

## Задание 1: Сортировка списка пузырьком.
Функция `bubble_sort(arr)` сортирует переданный список по возрастанию. Соседние элементы сравниваются и меняются местами, если левый больше правого. После каждого прохода выводится текущее состояние списка.

Переменная `swapped` отслеживает, были ли обмены. Если за проход ни одного обмена не произошло, сортировка завершается досрочно. Функция возвращает отсортированный список.
